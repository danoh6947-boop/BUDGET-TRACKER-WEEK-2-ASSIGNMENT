# My Budget Tracker

## About the Project

My Budget Tracker is a simple HTML and CSS project for recording and displaying personal expenses. It allows users to enter an expense name, amount, and category, while displaying sample expenses in a table.

## Files

### index.html

The `index.html` file contains the structure of the Budget Tracker. It includes the Add Expense form, category dropdown, expense table, logo, YouTube video, and How to Use section.

### style.css

The `style.css` file controls the appearance of the Budget Tracker. It styles the form, table, buttons, inputs, table rows, and multimedia section. It also uses advanced CSS selectors such as `:focus`, `:nth-child()`, `:first-child`, `:not()`, and descendant selectors.

## Features

- Add Expense form
- Expense category dropdown
- Expense table with five sample expenses
- Logo image
- Budgeting video
- How to Use collapsible section
- Table row hover effect
- Input focus effect
- Styled button

## Technologies Used

- HTML5
- CSS3
